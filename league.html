01 / 시장 데이터 준비

실제 데이터가 없어도 표본으로 흐름을 확인할 수 있습니다. 업로드한 스냅샷은 해시와 함께 보존됩니다.

JSON 데이터 형식

61행 이상의 날짜 오름차순 OHLC가 필요합니다. 출처와 합성 데이터 여부를 명시하세요. 날짜는 데이터의 거래일이며 서버가 거래일 캘린더를 검증하지는 않습니다.

{"symbol":"SOXL","source":"공급원 이름","synthetic":false,
 "price_basis":"split-adjusted",
 "rows":[{"date":"2026-01-02","open":40,"high":42,"low":39,"close":41}]}
위 예시는 형식 설명용 1행입니다. 업로드에는 61행 이상이 필요합니다.

02 / 독립 전략 실행

같은 스냅샷을 다시 실행하면 기존 결과를 반환합니다. 각 팀은 $10,000의 가상 초기자금을 기준으로 수량을 제안하며, 현금과 포지션을 실제로 변경하지 않습니다.

04 / 후속 가격으로 평가

기존 가격을 그대로 유지하고 이후 가격을 추가한 스냅샷으로 전망을 평가합니다. 각 기간은 별도 $10,000 실험이며, 수익률을 복리 합성하거나 리그 잔고를 변경하지 않습니다. 가정 체결은 익일 시가 진입·기간 말 종가 청산, 편도 슬리피지 0.1%와 수수료 $1을 적용합니다.

후속 스냅샷은 위 ‘독립 전략 실행’의 데이터 선택 상자에서 고르세요. 표본은 100봉 연구 → 120봉 후속 표본 순으로 확인합니다.

SQLite에 입력·연구 결과를 저장합니다. 기존 패턴랩의 브라우저 거래 기록과는 별개입니다. 해시 체인은 로컬 무결성 검사이며 외부 공증이나 DB 관리자에 대한 변조 방지는 아닙니다.
