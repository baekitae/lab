# Pattern Lab AI Team League 2.0

API 키 등록 화면, Gemini 회의, 시세 대조, 연속 모의 원장, 원장 감사, 승강 심사, 백업·복구를 한 프로그램에 묶은 통합 버전입니다. 실제 주문 기능은 없습니다.

**현재 검증 상태:** 자동 테스트·시험 응답 기반 전체 브라우저 흐름은 통과했습니다. 실제 Google에서는 8개 역할의 모델 접근과 간단한 JSON 생성은 확인했지만, 전체 회의 요청이 HTTP 503으로 보류되었습니다. Windows DPAPI의 실제 Windows 실행과 원본 113건 검증도 아직 완료되지 않았습니다. 기능 구현과 실운영 검증을 구분한 상세 내용은 [출시 점검표](docs/RELEASE_CHECKLIST.md)에 있습니다.

## PC에서 실행

1. 기존 패턴랩 서버 창을 종료합니다. 기존 데이터 폴더는 지우지 마세요.
2. 새 ZIP을 별도 폴더에 모두 압축 해제합니다.
3. Python **3.12 이상**을 설치합니다. Windows 설치 시 **Add Python to PATH**를 선택합니다.
4. Windows: **`start_windows.bat` 더블클릭**. 첫 실행은 고정 버전 의존성을 설치하므로 인터넷 연결이 필요합니다.
5. 자동으로 열린 통합 홈에서 **`① API 연결 설정`**을 누릅니다.

Mac/Linux에서는 폴더에서 `bash start_mac_linux.sh`를 실행합니다. 서버 창을 닫으면 자동 회의도 중지됩니다.

## 키는 어디에 넣나요?

**통합 홈 → ① API 연결 설정 → 각 역할의 `API 키` 입력 칸**입니다. 8개 역할 카드가 있고, 위·아래의 저장 버튼으로 등록합니다.

1. 먼저 A팀 키를 입력하고 **설정·키 저장**을 누릅니다. 나머지 키도 함께 등록할 수 있습니다.
2. **등록된 키로 실제 모델 목록 불러오기**로 사용 가능한 모델을 조회합니다.
3. 공통 모델을 선택하고 확인된 입력/출력 원화 단가, 월 예산을 설정합니다. 현재 계정에서 `gemini-3.8-flash` 목록 접근을 확인했습니다. 모델 가용성과 무료 자격은 프로젝트별로 다를 수 있습니다.
4. 무료 자격을 실제로 확인했다면 단가를 0으로 입력하고 확인 항목을 체크합니다. 확인 없이 무료라고 가정하지 않습니다.
5. 나머지 역할 키와 실제 프로젝트 ID·확인한 호출 한도를 등록합니다. 키별 실제 프로젝트 소속은 Google에서 확인해야 합니다.
6. 저장 후 상단 **AI 회의·보고서**로 이동합니다. 간단한 모델 목록 조회와 실제 회의 생성은 별개입니다.

키 발급/확인: https://aistudio.google.com/api-keys

키는 브라우저 저장소, 소스, JSON 내보내기, ZIP에 저장하지 않습니다. Windows에서는 현재 Windows 사용자에 묶인 **DPAPI 암호화 파일**에 저장합니다. Linux/macOS 입력 키는 **프로세스 메모리만** 사용하며 재시작하면 다시 입력하거나 OS/클라우드의 보안 환경 값을 사용해야 합니다. 환경에서 관리하는 키는 화면에 값을 표시하지 않으며 이 화면에서 덮어쓰지 않습니다.

암호화 저장소를 다른 Windows 사용자로 옮겼거나 파일이 손상되면, 설정 화면의 **원본 보존 후 연결 저장소 재설정**으로 암호화 원본을 남기고 새로 등록할 수 있습니다.

## 시장 데이터와 회의

- **② 시장 데이터**에서 한국투자 / Stooq 커넥터를 등록하거나 공급원 CSV를 가져옵니다.
- 공급원의 이용 조건과 실제 분할 조정 정책을 확인한 경우에만 활성화합니다. 라이선스/조정 정책을 프로그램이 추측하지 않습니다.
- CSV 형식은 `date,open,high,low,close`. 원본 파일·인코딩·해시·수집 시각을 보존합니다.
- 공급원 두 개를 선택하고 검증합니다. 다른 공급원 식별자, 같은 종목·조정 기준·분할 이벤트, 공통 최근 60거래일, 최신 확정 가격, OHLC 차이 0.5% 이하를 확인합니다. 공급원 식별/조정 정책은 사용자 확인이며 외부 공증은 아닙니다.
- 실제 데이터가 없을 때는 **기준 전략 연구실**에서 합성 표본을 추가해 연구할 수 있습니다. 합성 데이터는 운영 게이트나 실제 성과로 처리하지 않습니다.
- **AI 회의·보고서**에서 스냅샷을 선택해 회의를 시작합니다. 실패·미완료·보류를 완료로 표시하지 않습니다.

## 회의·평가·운영

- 독립 초안 4회 → 상호 공개·반박 4회 → 팀장 후보 비교 → 레드팀 → 총괄 → 독립 AI 감사.
- 다른 팀 초안은 최초 독립 작성 중에 전달하지 않습니다. 수정안 작성 순서 때문에 뒷팀이 먼저 작성된 수정안을 보는 것도 차단합니다.
- 가격 인용·확률·수량·기간을 Python으로 검증합니다. 월 예산·프로젝트별 로컬 한도·총 12회 요청 제한, 최대 두 번 재심을 적용합니다.
- 미래 스냅샷으로 방향 적중·상승 Brier·비용 반영 손익·종가 MDD, 토론 전후/그림자 후보 효과를 채점합니다.
- **③ 모의거래·성적표**에서는 팀별 $10,000의 현금·보유량을 이어갑니다. 조건을 확인한 주문만 익일 시가에 가정 체결하며 편도 0.1% 슬리피지·$1 수수료·위험/현금 제한을 적용합니다.
- 기준선: 단순 보유, 현금, 과거 20봉 이동평균 규칙, 토론 없는 독립 초안. 가상 포지션을 실제 계좌와 섞지 않습니다.
- 이전 일별 정산 가격이 수정되면 정산을 보류합니다. 비조정 주가에서는 명시된 분할 비율을 반영합니다. 분할 조정 데이터의 단위가 바뀌면 자동 추정하지 않고 보류합니다.
- 운영 홈에서 자동 회의를 켜면 NYSE 거래일 장 종료 15분 후 검증된 데이터로 하루 한 번 실행합니다. 휴장·조기 폐장·미국 DST는 고정 버전 `exchange-calendars`의 XNYS 캘린더(2000~2035 범위)를 사용합니다.
- 자동 모의 주문은 취소 조건을 임의 해석하지 않도록 활성화하지 않습니다. 회의 결과를 검토하고 모의 주문을 접수하세요.
- **긴급 중지**는 이후 AI 호출·공급원 연결·모의 접수를 중단합니다. 이미 전송된 한 요청의 응답은 도착할 수 있습니다. 중지·해제 이력을 보존합니다.

## 원장·이관·승강 심사

원장 CSV/전체 백업 JSON은 연구 시작의 필수 조건이 아닙니다. 실계좌 기준 승인 게이트에는 전체 원장 검증이 필요합니다.

- **원장·기존 데이터**: UTF-8/CP949, 키움 주문·체결 2행 / 거래·정산 3행, 한국어 또는 정규화 CSV를 지원합니다.
- 정규화 필수 열: `date,symbol,side,qty,price`; 선택: `fees,tax,trade_id,order_date,settlement_date`. 숫자 및 구분자 처리는 지원 형식 범위에서 수행합니다.
- 체결 0주 제외, 거래 ID 우선 중복 처리, 같은 조건·다른 날짜 후보 검토, 초과 매도·잔고 단절 검출. 원본 행을 지우거나 누락 매도를 만들지 않습니다.
- 미제공 주문일·정산일은 미상으로 남깁니다. 수수료 미포함 주문형식의 0은 잠정값입니다. 증권사 수량·평단·실현손익·수수료·세금을 별도 대조하고 전체 이력을 확인해야 게이트를 통과합니다. 이는 사용자 확인 기준이며 원본 completeness의 자동 보증이 아닙니다.
- 기존 JSON은 원본 보존 → 스키마/종목 참조/잔고 기준 드라이런 → 명시적 이관 확정 순서입니다. 기존 브라우저 기록을 자동으로 덮어쓰지 않습니다.
- **승강 심사**는 미래 평가 전 기준을 고정합니다. 최소 6개월, 비중첩 미래 표본 30개, 시장 국면 3개가 부족하면 유예합니다.
- 정규팀 대비 도전자 및 팀장 그림자 후보의 수익·위험·Brier 종합 개선을 검토합니다. 권고 후 사용자가 적용하며 과거 버전은 보존합니다. 한 심사에서는 한 가지 전략 변경만 적용하고, 변경 후 새 심사 기준을 고정합니다.

## 백업·복구

**백업·복구**에서 세 SQLite DB와 비밀이 아닌 설정을 ZIP으로 내려받습니다. 키·DPAPI 파일은 내보내지 않습니다.

복원: ZIP 선택 → 파일/해시/SQLite/이벤트 체인 검사 → 복원 확인 → 현재 상태 자동 백업 후 복원. 키는 변경하지 않습니다. 암호화 원본/설정 초기화 보존본은 `data/recovery`에 별도로 남으며 일반 내보내기에 포함하지 않습니다.

앱 내 백업은 비압축 합계 200MB, 복원 ZIP은 100MB 한도입니다. 더 큰 데이터는 서버를 중지하고 SQLite 온라인 백업으로 별도 관리하세요.

## 검증과 개발

```sh
.venv/bin/python -m unittest discover -s tests -v
node tests/walk_forward.cjs
```

브라우저 시험은 Playwright/Chromium이 있는 개발 환경에서 별도 시험 서버로 실행합니다. 운영 DB·실제 키·Google 호출을 사용하지 않습니다.

```sh
.venv/bin/python tests/serve_app_fixture.py --test-only
# 다른 터미널:
node tests/browser_app.cjs
```

원본 패턴랩 백테스트는 이번 버전에서 수정했습니다: 하락 신호를 가상의 공매도 이익으로 바꾸지 않고 현금 유지, 익일 시가 진입, 비중첩 신호 선택, 일별 자산의 MDD. 겹친 예측은 방향 평가에만 사용합니다.
