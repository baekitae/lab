# 연결 설정 개선판

- 한국투자 App Key / App Secret은 등록 후 입력칸에 다시 표시하지 않습니다. 두 키의 등록 상태를 별도로 표시합니다.
- ‘한국투자 키만 저장’은 Gemini 모델이나 요금 설정이 미완료여도 저장합니다. 빈 입력칸은 기존 값을 유지합니다.
- ‘저장된 한국투자 키로 인증 확인’은 실전투자 API 서버의 인증 토큰 발급을 확인합니다. 토큰과 키를 화면에 반환하지 않습니다. 시세 수신 및 이용 자격 확인과 실제 주문 실행을 뜻하지 않습니다.
- 키를 변경하면 이전 인증 토큰과 시세 캐시를 무효화합니다.
- Gemini는 키 저장 → 모델 목록 불러오기 → 조회된 모델 선택 → 설정 저장 순서입니다. 요금은 해당 프로젝트의 실제 단가를 입력해야 합니다. 무료 자격을 확인한 경우에만 0원을 입력합니다.

## 기존 사용자의 업데이트

실행 중인 패턴랩 서버 창을 종료합니다. 이번 ZIP을 별도 폴더에 압축 해제한 후, 그 안의 `app.html`, `server.py`, `connectors.py`, `bootstrap.py`, `start_windows.bat` 다섯 파일을 **기존 패턴랩 폴더**에 덮어씁니다. 기존 `data` 폴더는 변경하지 않습니다. 같은 Windows 사용자 계정에서 `start_windows.bat`을 실행하고 브라우저에서 Ctrl+F5로 새로고침합니다.

별도 새 폴더에서 실행하면 기존 폴더의 키와 원장은 자동으로 불러오지 않습니다. API 키는 백업 ZIP에도 포함되지 않습니다.

## 검증 범위

자동 테스트 66개 통과. 임시 서버와 가짜 공급원으로 한국투자 키 별도 저장, 키 마스킹, 인증 확인 UI, 모델 선택과 기존 전체 브라우저 흐름을 검증했습니다. 실제 한국투자 인증은 사용자의 PC에서 확인 버튼으로 수행해야 합니다. 개발 환경에서는 사용자 한국투자 키로 인증하지 않았습니다. Windows 실기 저장 검증 및 전체 Gemini 회의의 공급자 503 보류는 기존 점검표와 같습니다.


## 시세 갱신 오류 개선

공급원 등록은 설정 저장이며 실제 다운로드 성공이 아닙니다. 저장된 종목·가격 기준·이용 조건을 화면에 복원합니다. 화면 설정을 바꿨다면 다시 등록한 후 갱신해야 합니다. 한국투자 일봉 조회에서 발생한 오류는 일반 실패 문구 대신 인증 확인 및 권한·호출 제한 확인 순서를 표시하며, 응답에 있는 인식 가능한 HTTP/API 오류 코드만 노출합니다. 공급자가 원인을 주지 않았다면 구체적인 코드가 없을 수 있습니다. API 키와 원본 응답은 오류에 포함하지 않습니다.

개발 검증에서는 공급자 실패를 가짜 응답으로 재현했습니다. 사용자의 실제 시세 갱신 실패 원인은 이 화면만으로 확정하지 않았습니다.


## Stooq 자동 다운로드 제한 (2026-10-30)

개발 환경의 실제 SOXL 조회에서 HTTP 200이지만 `text/html` 브라우저 JavaScript 확인 화면을 반환하는 것을 확인했습니다. 사용자 노트북에서도 같은 원인인지는 기존의 일반 오류만으로 확정하지 않습니다. 수정판은 브라우저 확인·일반 HTML·빈 데이터·필수 열 누락·잘못된 가격·HTTP 403/429·네트워크 실패를 구분합니다. 제한을 우회하거나 다른 공급원으로 몰래 대체하지 않습니다. HTML을 시세로 저장하지 않으며, 한국투자 데이터와 키는 그대로 유지합니다. 정상적인 외부 CSV를 확보하면 CSV 가져오기로 등록할 수 있습니다. 두 번째 공급원 확보 전에는 두 공급원 검증을 통과했다고 표시하지 않습니다.
