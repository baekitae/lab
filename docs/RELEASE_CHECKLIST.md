## 실제 Google 호출 결과

- 환경에 이미 등록된 8개 키를 재사용했습니다. 키 값을 출력하거나 내보내지 않았습니다.
- `Gemini 3.8 Flash` 표시 이름을 `gemini-3.8-flash` ID로 정규화했습니다.
- 실제 모델 목록과 모델 메타데이터 조회 성공, POST countTokens 성공.
- 작은 JSON `{ "ok": true }` 생성 성공. 실제 사용량은 AI 호출 원장에 기록했습니다.
- 전체 회의 첫 요청은 응답 지연으로 보류되었습니다. 공식 문서/Discovery에서 Gemini 3.8의 LOW thinking 지원을 확인하고 낮은 thinking·180초 제한을 적용했습니다.
- 이후 전체 회의 재심에서도 **HTTP 503**이 반환되었습니다. 최대 두 번 재심을 소진한 검증 회의는 보류로 보존했습니다. 실패한 단계를 완료로 표시하거나 다른 모델/키로 우회하지 않았습니다.
- 간단한 생성 성공은 전체 회의 성공이나 무료 자격·실제 청구 0원을 증명하지 않습니다. 공급자 상태와 실제 프로젝트 한도/결제를 확인한 뒤 정상 운영 데이터의 회의로 다시 검증해야 합니다.

- Python 자동 테스트 62개 통과: 제공자 계약, 블라인드 입력, 원자적 비용, 공개 범위, 보고서 수치, 중복·취소·재심, CSV/CP949/브로커 형식, 원장 대조, DST, 포트폴리오, 심사, 비밀 값 마스킹, 저장소 보존/초기화, CSRF/Host, 백업·복원·로그 훼손 차단.

- Node walk-forward 검사 통과: 중첩 수익률 합성 금지, 익일 진입, 롱/현금, 일별 낙폭, 비용.
