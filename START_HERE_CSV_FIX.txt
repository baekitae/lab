Pattern Lab CSV 자동인식 확인판 — 2026-10-22

1. 기존 패턴랩에서 전체 백업(JSON)을 다운로드합니다.
2. 기존 서버를 실행한 검은 명령창에서 Ctrl+C로 서버를 완전히 종료합니다.
3. 이 ZIP을 새 폴더에 압축 풀고 start_windows.bat 실행.
4. 브라우저에서 http://127.0.0.1:8768 새로고침(Ctrl+F5).
5. 우측 상단에 "CSV 자동인식 적용 · 2026-10-22" 표시가 있어야 합니다.
6. SOXL > CSV 일괄 가져오기 > 원본 CSV 선택 후 미리보기 검사.
7. 겹치는 거래기간의 주문·체결/거래·정산 파일을 함께 확정 등록하면 중복 위험이 있습니다.

실행 창이 "Address already in use" 또는 WinError 10048을 보이면 이전 서버가 남아 있는 것입니다.
일반 CSV(거래 내역)와 주가 일봉 CSV는 서로 다른 버튼에서 읽습니다.
원본 백업 및 데이터는 ZIP에 포함되어 있지 않으며 기존 데이터를 삭제하지 않습니다.
수정: 시작 배치 파일(오류를 볼 수 있도록 콘솔 유지), 버전 확인 표시.
CSV 자동 인식 구현은 이전 수정판과 동일하며, Windows UI 통합 테스트는 미실시.
