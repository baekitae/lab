Pattern Lab v1.3.5 RC2 — CSV 원본·원장 대조 (2026-10-25)
기준: v1.3.5 RC1 (포트 8770)

변경 내용
- 매매 기록 추가 > CSV 일괄 가져오기 탭에 복수 CSV '원장 정밀 대조' 추가
- 주문·체결 2행, 거래·정산 3행, 일반 CSV를 읽고 기존 거래 원장과 비교
- 일치 / 날짜 차이·확인 필요 / 유사 거래·확인 필요 / 원장 누락 후보 / 원장에만 있는 거래 집계
- 수수료 차이와 주문일·정산일 차이를 확인할 수 있도록 7일 이내의 후보 탐색
- 비교 결과 JSON 다운로드. 해당 기능은 거래 등록/삭제/수정하지 않음
- 같은 파일의 반복 체결을 자동 합치지 않음

실제 테스트
- Node.js 구문 검사 통과
- 기존 4개 원본 CSV 파싱: 93/73/42/27건
- 2026-04-08 SELL 85 @66.20 원장 누락 후보 확인
- 113건 백업과 교차 대조 결과: 원본 235건 / 대조 그룹 176 / 확정 일치 73 / 수동 검토 36 / 누락 후보 67 / 원장에만 존재 6

주의 및 미완료
- 위 숫자는 여러 CSV 간 거래 기간이 중복되므로 매매 건수 자체를 뜻하지 않습니다.
- 같은 날짜·방향·수량·가격이 실제 서로 다른 체결일 수도 있습니다. 매칭은 후보 분류이며 사용자 확인이 필요합니다.
- 원장 누락 후보가 전부 실제 누락으로 확정된 것은 아닙니다.
- 자동 병합·회계 원장 복원 및 최종 38주/$164.2326 전체 역사 재현은 아직 미구현입니다.
- Windows 브라우저 통합 클릭 테스트는 실시하지 않았습니다.

실행
- 기존 8770 환경은 JSON 전체 백업 후 서버 종료
- 새로운 폴더에 ZIP 압축해제, start_windows.bat 실행
