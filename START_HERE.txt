Pattern Lab AI Team League 2.0

1. 기존 패턴랩 서버 창을 먼저 종료하세요. 기존 폴더와 데이터는 지우지 마세요.
2. 이 ZIP을 새 폴더에 모두 압축 해제하세요.
3. Python 3.12 이상을 설치하세요. Windows에서는 Add Python to PATH를 선택하세요.
4. start_windows.bat을 더블클릭하세요. 첫 실행은 의존성을 설치하므로 인터넷이 필요합니다.
5. 브라우저의 통합 홈에서 [① API 연결 설정]을 누르세요.
6. 각 역할의 [API 키] 칸에 키를 넣고 [설정·키 저장]을 누르세요.
7. 모델 목록을 실제 조회하고, 모델·단가·월 예산을 확인한 뒤 저장하세요.
8. 시장 데이터 두 공급원을 확인하고 [AI 회의·보고서]로 이동하세요.

Windows 키는 DPAPI로 암호화합니다. 키는 이 ZIP에 들어 있지 않습니다.
Linux/macOS에서는 입력 키를 세션 메모리만 사용하므로 재시작 시 다시 넣거나 보안 환경 값을 사용하세요.

현재 검증 제한:
- 모델 목록과 간단한 실제 Google JSON 생성은 확인했습니다.
- 실제 전체 회의는 Google HTTP 503으로 검증 보류입니다.
- Windows DPAPI의 실제 Windows 실행 검증은 별도로 필요합니다.
- 실제 원본 113건 및 6개월 미래 성과는 제공/축적 전이며 검증 완료로 표시하지 않습니다.
